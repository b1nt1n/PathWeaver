# Credits

## PathWeaver

[b1nt1n](https://github.com/b1nt1n) maintains PathWeaver, makes test levels, and tests the mod in game. He finished the artwork for the logo and pause button. Development and review used AI assistance, including OpenAI Codex.

## gdsolver

PathWeaver is based on [gdsolver](https://github.com/gdsolver/gdsolver) v0.6.1, pinned at `d09300a6f4c7946f26015fc86a6cb33e8c891a7a`. The original authors built the reachability solver, native verification and repair loop, and much of the infrastructure this fork extends.

The gdsolver authors' copyright and MIT license are in [LICENSE](LICENSE).

## Libraries and integrations

- [Geode](https://github.com/geode-sdk/geode) provides the mod loader and SDK.
- [GDReplayFormat](https://github.com/maxnut/GDReplayFormat/tree/d8d2f0b1193a46cdf47b413dc832616dd052b6a9) provides the pinned binary replay codec.
- [Eclipse](https://github.com/EclipseMenu) provides an external player and an optional timing integration. The export profile targets version 1.9.4.
- [xdBot](https://github.com/Zilko/xdBot) provides the external-player reference for the separate laboratory compatibility profile.
