# Upstream fork acknowledgment

The PathWeaver maintainer provided the upstream gdsolver author's reply during
release preparation on 2026-11-07. The original correspondence is retained by
the maintainer. The author expressly allowed quoting the statement in the
PathWeaver repository as evidence for a Geode submission.

> There is no objection to PathWeaver being released as a fork, and the MIT
> license, copyright notice and credits being kept is all that is needed from
> this side.

The reply also clarifies that this acknowledgment is not an endorsement of
PathWeaver's code and does not imply a line-by-line review. Code quality and
release responsibility remain with the PathWeaver maintainer. It does not
override Geode Index policies or guarantee acceptance.

The upstream MIT notice is preserved in [LICENSE](../LICENSE); attribution is
retained in [CREDITS.md](../CREDITS.md) and [about.md](../about.md).
